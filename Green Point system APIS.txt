2. POST /api/customer/coupons/validate
Request Payload
{
  "code": "SAVE10",
  "items": [
    {
      "variantId": 101,
      "quantity": 2
    },
    {
      "variantId": 102,
      "quantity": 1
    }
  ],
  "appliedCouponCodes": ["FIRST20"]
}
Response
{
  "success": true,
  "message": "Coupon validated",
  "data": {
    "valid": true,
    "couponCode": "SAVE10",
    "discountAmount": 100.00,
    "applicableAmount": 1000.00,
    "message": "Coupon applied successfully!",
    "allowStackable": true
  }
}
When Invalid
{
  "success": true,
  "message": "Coupon validated",
  "data": {
    "valid": false,
    "couponCode": "EXPIRED",
    "discountAmount": null,
    "applicableAmount": 1000.00,
    "message": "This coupon has expired",
    "allowStackable": false
  }
}
Field Descriptions
Field	Type	Description
valid	Boolean	Whether coupon can be applied
couponCode	String	The validated coupon code
discountAmount	BigDecimal	Discount value in INR
applicableAmount	BigDecimal	Amount the discount applies to
message	String	Validation message
allowStackable	Boolean	Can be combined with other coupons
---
Summary of Customer-Facing Green Points & Coupon APIs
API	Method	Purpose
/api/customer-account/rewards/balance	GET	Get points balance, expiring points, transactions
/api/customer/coupons/validate	POST	Validate a coupon code before checkout
Notes:
- Green Points Conversion: 1 point = ₹0.10 (10 points = ₹1)
- Minimum Redemption: 100 points required to redeem
- Points Expiry: Points expire after 90 days from earning
- Coupon Stackable: Some coupons can be combined, others cannot
